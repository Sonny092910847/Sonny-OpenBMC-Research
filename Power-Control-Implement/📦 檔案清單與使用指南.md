### 步驟 3: 部署和測試 🚀

#### 選項 A: 使用開發服務器（推薦⭐⭐⭐）

**優點：**
- ✅ 最快速（不需要重新編譯完整映像檔）
- ✅ 支援熱重載（修改立即生效）
- ✅ 不影響 Jenkins 原始映像檔

**步驟概覽：**

```bash
# 1. 準備 webui-vue 源碼
cd ~
git clone https://github.com/openbmc/webui-vue.git
cd webui-vue

# 2. 安裝依賴
npm install

# 3. 備份原始檔案
cp src/views/Operations/Kvm/KvmConsole.vue \
   src/views/Operations/Kvm/KvmConsole.vue.backup

# 4. 套用修改
cp "D:\Power Control Implement\KvmConsole-Modified.vue" \
   src/views/Operations/Kvm/KvmConsole.vue

# 5. 啟動開發服務器
npm run serve

# 6. 開啟瀏覽器測試
# http://localhost:8080
```

**詳細步驟請參考：** `安裝說明.md`

**如果遇到以下問題：**

1. **檔案無法在 Windows 存取**
   - 檢查 Docker Volume 掛載設定
