# 📦 安裝說明

## 方法 1：使用開發服務器（推薦）⭐⭐⭐

這是最快速、最簡單的測試方式！

### 步驟 1：準備 webui-vue 源碼

#### 選項 A：克隆新的 repo（推薦，乾淨）

```bash
# 在你的工作目錄
cd ~
git clone https://github.com/openbmc/webui-vue.git
cd webui-vue
```

#### 選項 B：使用現有的 webui-vue（如果有）

```bash
# 如果已經有 webui-vue
cd ~/openbmc/build/workspace/sources/webui-vue

# 確保是最新版本
git pull origin master
```

---

### 步驟 2：安裝 Node.js 依賴

```bash
# 在 webui-vue 目錄中
npm install
```

**預計時間：** 2-5 分鐘

**可能的問題：**
- 如果出現權限錯誤，確保有寫入權限
- 如果出現網路錯誤，檢查網路連線
- 如果 Node.js 版本太舊，建議升級到 Node.js 16+

---

### 步驟 3：備份原始檔案

```bash
# 備份原始的 KvmConsole.vue
cp src/views/Operations/Kvm/KvmConsole.vue \
   src/views/Operations/Kvm/KvmConsole.vue.backup

echo "✅ 原始檔案已備份"
```

---

### 步驟 4：套用修改

#### 在 Windows 上（從 D:\Power Control Implement）

```powershell
# 方法 A：使用 PowerShell
Copy-Item "D:\Power Control Implement\KvmConsole-Modified.vue" `
          "你的webui-vue路徑\src\views\Operations\Kvm\KvmConsole.vue"

# 方法 B：使用檔案總管
# 1. 開啟 D:\Power Control Implement\
# 2. 複製 KvmConsole-Modified.vue
# 3. 貼到 webui-vue\src\views\Operations\Kvm\
# 4. 重新命名為 KvmConsole.vue（覆蓋原檔案）
```

#### 在 Linux 上

```bash
# 假設修改檔案在 ~/Power-Control-Implement/
cp ~/Power-Control-Implement/KvmConsole-Modified.vue \
   ~/webui-vue/src/views/Operations/Kvm/KvmConsole.vue

echo "✅ 修改已套用"
```

---

### 步驟 5：設定開發服務器（如果需要）

**檢查 `vue.config.js` 是否有正確的代理設定：**

```bash
# 在 webui-vue 目錄中
cat vue.config.js
```

**應該包含類似這樣的內容：**

```javascript
module.exports = {
  devServer: {
    proxy: {
      '/': {
        target: 'https://localhost:8443',  // QEMU 的位址
        changeOrigin: true,
        secure: false
      }
    }
  }
}
```

**如果沒有或需要修改，編輯 `vue.config.js`：**

```javascript
const { defineConfig } = require('@vue/cli-service');

module.exports = defineConfig({
  transpileDependencies: true,
  devServer: {
    proxy: {
      '/': {
        target: process.env.BASE_URL || 'https://localhost:8443',
        changeOrigin: true,
        secure: false,
      },
    },
  },
  configureWebpack: {
    resolve: {
      alias: {
        vue$: 'vue/dist/vue.esm-bundler.js',
      },
    },
  },
});
```

### 步驟 6：確保 Jenkins QEMU 正在運行

**在另一個終端：**

```bash
cd ~/jenkins-romulus

# 啟動 QEMU（使用你的啟動命令）
./qemu-system-arm -m 256 -M romulus-bmc -nographic \
  -drive file=romulus.mtd,format=raw,if=mtd \
  -net nic \
  -net user,hostfwd=:127.0.0.1:2222-:22,hostfwd=:127.0.0.1:8443-:443,hostfwd=tcp:127.0.0.1:8080-:80,hostname=qemu
```

**確認 QEMU 正在運行：**

```bash
# 測試 SSH
ssh -p 2222 root@localhost

# 測試 WebUI
curl -k https://localhost:8443
```

### 步驟 7：啟動開發服務器

```bash
# 在 webui-vue 目錄中
npm run serve
```

**你應該會看到：**

```

  - Local:   http://localhost:8080/
  - Network: http://192.168.x.x:8080/

  Note that the development build is not optimized.
  To create a production build, run npm run build.
```

**⏰ 等待編譯完成...**（約 30-60 秒）

## 方法 3：手動更新 QEMU 中的前端檔案

### 步驟 1：編譯前端

```bash
cd ~/webui-vue
npm run build
```

這會產生 `dist/` 資料夾。

### 步驟 2：上傳到 QEMU

**方法 A：使用 SCP（QEMU 運行時）**

```bash
# 壓縮 dist 資料夾
cd ~/webui-vue
tar czf dist.tar.gz dist/

# 上傳到 QEMU
scp -P 2222 dist.tar.gz root@localhost:/tmp/

# SSH 到 QEMU
ssh -p 2222 root@localhost

# 在 QEMU 中解壓並複製
cd /tmp
tar xzf dist.tar.gz
rm -rf /usr/share/www/*
cp -r dist/* /usr/share/www/
systemctl restart bmcweb

# 清理
rm -rf /tmp/dist /tmp/dist.tar.gz
exit
```

**方法 B：掛載映像檔（需要 root 權限）**

⚠️ **危險操作！** 可能損壞映像檔，請先備份！

```bash
# 備份映像檔
cp ~/jenkins-romulus/romulus.mtd ~/jenkins-romulus/romulus.mtd.backup

# 掛載（需要 root）
sudo losetup -P /dev/loop0 ~/jenkins-romulus/romulus.mtd
sudo mount /dev/loop0p2 /mnt

# 更新檔案
sudo rm -rf /mnt/usr/share/www/*
sudo cp -r ~/webui-vue/dist/* /mnt/usr/share/www/

# 卸載
sudo umount /mnt
sudo losetup -d /dev/loop0
```

## 常見問題

### Q1: npm install 失敗

**解決方法：**
```bash
# 清除快取
npm cache clean --force

# 刪除 node_modules 重新安裝
rm -rf node_modules package-lock.json
npm install
```

---

### Q2: npm run serve 無法啟動

**檢查：**
```bash
# 檢查 Node.js 版本（需要 16+）
node --version

# 檢查 npm 版本
npm --version

# 檢查 8080 port 是否被占用
lsof -i :8080  # Linux/Mac
netstat -ano | findstr :8080  # Windows
```

---

### Q3: 瀏覽器無法連接 localhost:8080

**解決方法：**
1. 確認開發服務器正在運行
2. 檢查防火牆設定
3. 嘗試使用 `http://127.0.0.1:8080`

---

### Q4: 按鈕出現但點擊沒反應

**檢查：**
1. 按 F12 開啟開發者工具
2. 查看 Console 分頁是否有錯誤
3. 查看 Network 分頁是否有 API 請求
4. 確認 QEMU 正在運行

---

### Q5: API 請求失敗（401/403）

**原因：** 認證問題

**解決方法：**
1. 重新登入
2. 檢查 Token 是否過期
3. 確認使用正確的使用者名稱和密碼
