
```

4. 同時開啟 Network 分頁

```

### Q4: 我可以只測試按鈕，不實際發送命令嗎？

**A: 可以！** 修改 `powerOn()` 方法：

```javascript
async powerOn() {
  console.log('🔵 Power On 按鈕被點擊');
  console.log('📍 測試模式：不會實際發送命令');

  // 註解掉實際的 API 呼叫
  // await this.$store.dispatch('controls/serverPowerOn');

  // 只顯示提示
  this.$bvToast.toast('測試模式：未發送實際命令', {
    title: '🧪 測試模式',
    variant: 'info',
  });
}
```

---

### Q5: 能否直接在 Windows 上用 VSCode 修改？

**A: 要看您的環境設定**

如果您使用：
- **WSL**: 可以，Windows 可以直接存取 WSL 檔案
  ```
  \\wsl$\<發行版名稱>\home\user\...
  ```
- **Docker**: 需要先從容器複製出來
  ```bash
  docker cp <容器ID>:/tmp/... ./
  ```
- **純 Linux**: 使用 Samba 或 SFTP 共享
